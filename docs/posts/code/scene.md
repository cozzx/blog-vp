线程池使用场景：

1. 批量导入

   分页读取数据库数据，使用线程池写入es，使用countDownLounch机制，避免oom。

2. 数据汇总

   调用多个接口来汇总数据，如果接口之间没有依赖关系，可以使用线程池和future来提升性能。

3. 异步线程

   不影响主线任务的支线操作可以使用异步线程池。springboot启动类加@EnableAsync注解，在执行直线操作的方法中标注@Async注解，传入线程池bean name。

如何控制某个方法并发访问的数量

​	使用多线程提供的工具类semaphore，给定信号量的容量，使用acquire和release方法来获取释放信号量。
